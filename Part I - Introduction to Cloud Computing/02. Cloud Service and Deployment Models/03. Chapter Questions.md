## 2.10 Chapter Questions

**Q1.** A development team wants to deploy a web application without provisioning or patching servers, while still writing and controlling the application code. Which cloud service model does this describe?

- A. IaaS
- B. PaaS
- C. SaaS
- D. Hybrid cloud

**Answer: B.** *Target exam: AWS Certified Cloud Practitioner.* PaaS leaves the customer responsible for code and data while the provider handles the operating system, runtime, and scaling.

**Q2.** A company moves its email and document collaboration to a service that users reach through a browser, where the vendor handles all updates and maintenance. Which model is this?

- A. IaaS
- B. PaaS
- C. SaaS
- D. Private cloud

**Answer: C.** *Target exam: AWS Certified Cloud Practitioner.* The customer consumes a finished application and manages only its users, configuration, and data.

**Q3.** In which service models is the customer responsible for the data?

- A. IaaS only
- B. IaaS and PaaS only
- C. PaaS and SaaS only
- D. IaaS, PaaS, and SaaS

**Answer: D.** *Target exam: AWS Certified Cloud Practitioner.* Responsibility for data never transfers to the provider, whichever model is in use.

**Q4.** A manufacturer must keep a control system inside its factory because it requires sub-millisecond latency to equipment on the floor, but wants to run its analytics and reporting in AWS. Which deployment model fits?

- A. Public cloud
- B. Private cloud
- C. Hybrid cloud
- D. Community cloud

**Answer: C.** *Target exam: AWS Certified Solutions Architect - Associate.* The latency constraint pins one component on-premises while the rest of the workload runs in AWS, which is the definition of hybrid.

**Q5.** An architect is told that a workload cannot use public cloud because the infrastructure would be shared with other companies. Which response is technically correct?

- A. Shared infrastructure is unavoidable in public cloud, so a private cloud is required
- B. Tenants are isolated at the hypervisor and network layers, and dedicated hosts are available where a license or regulation requires single-tenant hardware
- C. Public cloud providers do not use multi-tenant infrastructure
- D. Encryption at rest removes all multi-tenancy concerns

**Answer: B.** *Target exam: AWS Certified Solutions Architect - Associate.* Isolation is enforced by design, and dedicated hosts exist precisely for the cases where single-tenant hardware is genuinely required.
