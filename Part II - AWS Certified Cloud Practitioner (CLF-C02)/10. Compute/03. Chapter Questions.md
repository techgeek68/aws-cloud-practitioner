## 10.16 Chapter Questions

**Q1.** Which EC2 pricing model offers the largest discount but can be reclaimed by AWS with two minutes of notice?

- A. Reserved Instances
- B. On-Demand Instances
- C. Spot Instances
- D. Dedicated Hosts

**Answer: C.** *Target exam: AWS Certified Cloud Practitioner.* Spot uses spare capacity at up to 90% off On-Demand, in exchange for accepting interruption on two minutes' notice.

**Q2.** A company needs to run a Python function once an hour to tidy up temporary files, with no servers to manage. Which service fits best?

- A. Amazon EC2 with a cron job
- B. AWS Lambda triggered by an Amazon EventBridge schedule
- C. AWS Elastic Beanstalk
- D. Amazon ECS on EC2

**Answer: B.** *Target exam: AWS Certified Cloud Practitioner.* A short scheduled task is the canonical Lambda use case, and it incurs no cost between invocations.

**Q3.** Which statement about EC2 instance store volumes is correct?

- A. Data persists when the instance is stopped and started
- B. Data persists when the instance is terminated
- C. Data is lost when the instance is stopped or terminated, but survives a reboot
- D. Instance store volumes can be detached and attached to another instance

**Answer: C.** *Target exam: AWS Certified Cloud Practitioner.* Instance store is physically attached to the host, and stopping an instance almost always moves it to a different host.

**Q4.** A developer wants to deploy a Node.js web application without configuring load balancers, Auto Scaling groups, or EC2 instances directly. Which service is the best fit?

- A. Amazon EC2
- B. AWS Elastic Beanstalk
- C. Amazon EKS
- D. AWS Batch

**Answer: B.** *Target exam: AWS Certified Cloud Practitioner.* Beanstalk provisions and manages that infrastructure from uploaded code while leaving the underlying resources accessible.

**Q5.** An application runs continuously on 20 EC2 instances of a fixed type and is expected to do so for the next three years. Which purchasing approach minimizes cost while preserving the ability to change instance family later?

- A. On-Demand Instances
- B. Spot Instances
- C. A Compute Savings Plan with a three-year term
- D. Standard Reserved Instances for a specific instance type

**Answer: C.** *Target exam: AWS Certified Solutions Architect - Associate.* Compute Savings Plans give a comparable discount to Reserved Instances while applying across instance families, Regions, and also to Lambda and Fargate.

**Q6.** A workload is containerized and the team wants to run it without managing or patching any EC2 instances. Which combination meets this?

- A. Amazon ECS with the EC2 launch type
- B. Amazon ECS or Amazon EKS with AWS Fargate
- C. Amazon EC2 with Docker installed manually
- D. AWS Elastic Beanstalk with a single-instance environment

**Answer: B.** *Target exam: AWS Certified Solutions Architect - Associate.* Fargate runs containers without exposing or requiring management of the underlying instances, unlike the EC2 launch type.
