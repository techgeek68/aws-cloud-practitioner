## 6.8 Chapter Questions

**Q1.** A company adopting AWS is struggling with staff resistance, a skills shortage, and unclear training paths. Which AWS CAF perspective addresses this?

- A. Business
- B. Governance
- C. People
- D. Operations

**Answer: C.** *Target exam: AWS Certified Cloud Practitioner.* The People perspective covers culture evolution, cloud fluency, workforce transformation, and change acceleration.

**Q2.** During which phase of the AWS CAF transformation journey does an organization identify capability gaps across the six perspectives and produce an action plan?

- A. Envision
- B. Align
- C. Launch
- D. Scale

**Answer: B.** *Target exam: AWS Certified Cloud Practitioner.* Envision identifies opportunities and outcomes; Align assesses readiness, finds gaps, and builds the plan to close them.

**Q3.** Which pillar of the AWS Well-Architected Framework is concerned with minimizing the environmental impact of running workloads?

- A. Cost Optimization
- B. Operational Excellence
- C. Performance Efficiency
- D. Sustainability

**Answer: D.** *Target exam: AWS Certified Cloud Practitioner.* Sustainability addresses environmental impact through higher utilization, more efficient hardware such as Graviton, and reducing retained data.

**Q4.** Which statement best describes the relationship between the six Well-Architected pillars?

- A. All six can be fully satisfied simultaneously in any well-designed workload
- B. The pillars often involve trade-offs, and the framework exists to make those trade-offs deliberate and documented
- C. Security takes absolute precedence and the other five apply only afterwards
- D. The pillars apply only to workloads running on Amazon EC2

**Answer: B.** *Target exam: AWS Certified Solutions Architect - Associate.* Reliability, cost, performance, and security pull against one another, and the framework's value is in surfacing those tensions rather than pretending they do not exist.

**Q5.** An architect wants to verify that a production workload follows AWS best practices, receive a list of risks by severity, and track improvement over time. Which approach fits?

- A. Enable AWS Trusted Advisor and review the cost checks
- B. Run a review in the AWS Well-Architected Tool, record milestones, and re-run it periodically
- C. Deploy the workload with CloudFormation and rely on template validation
- D. Open a support case requesting an architecture assessment

**Answer: B.** *Target exam: AWS Certified Solutions Architect - Associate.* The Well-Architected Tool produces a risk-ranked report per workload and uses milestones to make progress between reviews measurable.
